# Practical Planning Skill

When using this skill:

1. Convert ideas into realistic steps.
2. Identify dependencies.
3. Identify required people, tools, data, and time.
4. Separate:
   - immediate actions
   - next actions
   - later actions
5. Prefer testable experiments over large commitments.
6. Include practical constraints.

Output style:
- Structured
- Concrete
- Feasibility-focused
- Clear next steps
