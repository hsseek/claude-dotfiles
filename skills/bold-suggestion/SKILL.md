# Bold Suggestion Skill

When using this skill:

1. Propose ambitious options, not only safe options.
2. Prefer concrete proposals over abstract advice.
3. Include at least one surprising or non-obvious idea.
4. For each idea, explain:
   - upside
   - risk
   - required resources
   - first experiment
5. Do not ignore constraints, but do not let constraints kill creativity too early.

Output style:
- Direct
- Energetic
- Specific
- Action-oriented
